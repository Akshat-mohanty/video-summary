##  Overview

**Summarize** is a minimalist, editorial-grade web application that analyzes any YouTube video and synthesizes a concise, factual summary in **under 150 words**.

It extracts the actual spoken transcript directly from closed captions and uses Google's latest **Gemini 2.5 Flash** model to recount what actually happens in the video without fluff, formulas, or assumptions.

---

##  Features

-  **Strict 150-Word Limit**: Read what happens in under 45 seconds.
-  **Direct Spoken Captions**: Analyzes actual spoken word-for-word transcript.
-  **Zero Assumptions**: Recounts real events, steps, numbers, and facts without making up hypothetical claims.
-  **Built-in Text-to-Speech**: Listen to the generated summary aloud directly in your browser.
-  **1-Click Copy**: Copy formatted summaries instantly with visual confirmation.
-  **Responsive & Clean UI**: Luxury cream & obsidian editorial aesthetic powered by Framer Motion.

---

##  Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Modern CSS3 (Editorial Design System, Glassmorphism, CSS Grid)
- **Animations**: Framer Motion
- **AI Model**: Google Gemini 2.5 Flash API
- **Deployment**: Vercel
